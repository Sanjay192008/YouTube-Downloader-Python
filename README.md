🎬 YouTube Video Downloader

A simple and efficient YouTube video downloader built using Python. This project allows users to download videos from YouTube in high quality directly to their system.

🚀 Features

* Download YouTube videos
* Simple and user-friendly interface
* Fast and efficient performance

🛠️ Tech Stac

* Python
* pytube

▶️ How to Run

1. Clone the repository

```id="yt02cd"
git clone https://github.com/Sanjay192008/yt-downloader.git
```

2. Navigate to the project folder

```id="yt03ef"
cd yt-downloader
```

3. Install dependencies

```id="yt04gh"
pip install -r requirements.txt
```

4. Run the program

```id="yt05ij"
python main.py
```

---



📌 Usage

* Enter the YouTube video URL
* Select desired quality
* Video will be downloaded to your system
